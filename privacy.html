隱私權政策

最後更新：2026-11-06

  • 誰在用：本工具只供擁有者本人使用，沒有其他使用者。
  • 取用哪些資料：經擁有者同意後，讀寫擁有者本人 Google 帳號中的日曆、雲端硬碟、文件與試算表。
  • 資料去哪裡：資料只存在擁有者自己的電腦與 Google 帳號中，不出售、不分享給第三方，也不用於廣告。
  • Google 使用者資料：本工具使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包括「有限使用」（Limited Use）要求。
  • 撤銷授權：可隨時在 Google 帳號權限頁 移除本工具的存取權。

Privacy Policy

Last updated: 2026-11-06

  • Users: This tool is used only by its owner. There are no other users.
  • Data accessed: With the owner's consent, it reads and writes the owner's own Google Calendar, Drive, Docs and Sheets.
  • Storage and sharing: Data stays on the owner's computer and Google account. It is never sold, shared with third parties, or used for advertising.
  • Google user data: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: Access can be removed at any time at Google Account permissions.
